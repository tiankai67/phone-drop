# Phone Drop

用手机扫二维码，把照片、视频或文本传到运行本服务的电脑 / 服务器。

- 桌面浏览器打开后会显示一个二维码，二维码指向 `/upload` 上传页；
- 手机（同设备浏览器或扫码）打开后选择文件，或从手机端直接发送文本；
- 收到的文件保存到 `received-files/`，收到的文本保存为 `received-files/note_*.txt` 并在桌面端实时展示。

## 本地使用

### 方式一：一键启动（Windows 推荐）

下载仓库后，双击 **`PhoneDrop.vbs`**（或 `start-phone-drop.bat`）：

- 自动定位本机 Node.js（PATH → 常见安装路径 → 内置兜底）；
- 自动启动服务（默认 http://127.0.0.1:3456）；
- 自动用默认浏览器打开网页；
- 关闭弹出的提示框即停止服务（端口会被精确清理，不留残留进程）。

> 说明：`PhoneDrop.vbs` 是纯 VBScript 启动器，双击运行**无黑色命令行窗口**。若系统策略拦截 VBS，可改用 `start-phone-drop.bat`（会有一个黑色窗口）。

### 方式二：命令行

```bash
npm install
node server.js
# 默认监听 http://localhost:3456
```

## 文本传输（新增）

除文件上传外，手机端 `/upload` 页面新增「发送文本」卡片：

- 在手机上输入文字，点击发送；
- 文本会以 `note_<时间戳>.txt` 保存到电脑的 `received-files/`；
- 电脑首页「收到的文本」区域每 2 秒刷新，实时显示最新文本，方便临时拷贝链接、验证码等小段内容。

## 公网部署（Render 示例）

本项目是一个 Node.js 服务，**无法用 GitHub Pages 托管**，需要能运行 Node 的平台。以 [Render](https://render.com) 为例：

1. 把本仓库推到 GitHub；
2. 在 Render 新建 **Web Service**，关联该 GitHub 仓库；
3. Render 会自动用 `npm install` 安装依赖、`node server.js` 启动；
4. 在 Render 的环境变量里设置 `PASSWORD`（可选但强烈建议，见下）。

其他平台（Railway、Fly.io、Koyeb 等）同理：`npm install` + `node server.js`，平台会注入 `PORT`。

## 访问口令（计划中）

> 注：`PASSWORD` 认证为后续计划功能，**当前发布版本尚未在代码中实现**。当前版本面向纯局域网使用，无需口令；若用于公网部署，请注意上传接口默认无认证、任意人都可往服务器传文件的安全风险。

设置环境变量 `PASSWORD` 后（计划中）：

- 桌面页与手机页需要带正确口令才能使用（地址后加 `?pw=你的口令`，或由页面输入）；
- 二维码本身会编码口令，手机扫码即可直接上传；
- 不设 `PASSWORD` 时行为与原版完全一致（适合纯局域网使用）。

```bash
PASSWORD=你的强口令 node server.js
```

## 环境变量

| 变量       | 默认值 | 说明                                   |
| ---------- | ------ | -------------------------------------- |
| `PORT`     | `3456` | 监听端口（部署平台通常自动注入）       |
| `PASSWORD` | 空     | 访问口令（计划中，当前未实现）         |

## 说明

- 单文件最大 1GB；
- 文件名会自动清理非法字符，重名文件自动加序号；
- 支持「文件上传」与「文本传输」两种方式；
- `public/Aws.exe` 为原作者机器上的无关文件，仓库中已排除。
